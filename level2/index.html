재사용 무기: 각도 함수

calculate_angle(a, b, c)는 가운데 점 B를 꼭짓점으로 하는 각도를 도 단위로 반환합니다. BA = A − B, BC = C − B를 만든 뒤 벡터 내적 공식을 적용합니다. 이번에는 B가 무릎이 아니라 팔꿈치여도 계산 방법은 같습니다.

  1. cos θ = (BA · BC) / (|BA| × |BC|) — 내적을 두 벡터 길이의 곱으로 나눕니다.
  2. θ = arccos(cos θ) — 코사인값에서 각도를 되찾고, np.degrees로 라디안을 도로 바꿉니다.
Level 1 · 벡터 내적 설명 다시 읽기

아래는 practice1_pushup.py의 27–40줄 그대로입니다. Level 1의 03angle_01.py와 계산식·계산 순서·반환 결과가 동일합니다. 주석은 짧게 정리했고, 마지막 결과를 angle 변수에 담는 대신 바로 반환합니다.

def calculate_angle(a, b, c):
    """b를 꼭짓점으로 하는 a-b-c 각도(도)를 반환"""
    a = np.array(a)
    b = np.array(b)
    c = np.array(c)
    # Level 1과 같은 벡터 내적 + arccos
    ba = a - b
    bc = c - b
    dot_product = np.dot(ba, bc)
    magnitude_ba = np.linalg.norm(ba)
    magnitude_bc = np.linalg.norm(bc)
    cosine_angle = dot_product / (magnitude_ba * magnitude_bc)
    cosine_angle = np.clip(cosine_angle, -1.0, 1.0)
    return np.degrees(np.arccos(cosine_angle))
np.clip은 수치 오차를 막는 안전장치

코사인값이 계산 오차로 −1~1을 조금 벗어나더라도 경계로 잘라 arccos에 전달합니다. 단, 점이 겹쳐 벡터 길이가 0이 되는 문제까지 해결하지는 않습니다.

이 함수는 오늘 practice1_pushup.py, practice3_multi_coach.py, practice4_workout_king.py, practice5_plank.py 네 파일에서 그대로 쓰입니다. 팔벌려뛰기 전용인 practice2_jumpingjack.py는 각도 대신 위치와 거리를 비교하므로 사용하지 않습니다.

한 번 잘 만든 함수는 계속 쓴다 — 이것이 재사용입니다. 함수 안의 수학은 그대로 두고, 다음 실습에서는 어떤 관절을 넣을지만 바꿔 보겠습니다.

전체 코드를 기능별로 읽어 봅시다

아래 블록은 파일 처음부터 끝까지 순서대로 나눈 것입니다. 블록 하나만 실행하는 것이 아니라 다운로드한 전체 파일을 실행하세요. calculate_angle은 바로 앞에서 본 함수이므로 짧게 확인하고 넘어갑니다.

반복문 주석의 (1) 관절 고르기 → (2) 각도 재기 → (3)(4) 판정＋카운트가 복습 카드의 네 단계와 정확히 대응합니다. 긴 프로그램처럼 보여도 우리가 정하는 핵심은 이 네 단계입니다.

"""
========================================================================
practice1_pushup.py  -  푸쉬업 카운터 (팔꿈치 각도)
========================================================================
[지난 시간 복습]
  스쿼트 카운터의 "레시피" 4단계
    1) 관절 고르기   2) 각도 재기   3) UP / DOWN 기준 정하기   4) 카운트

[오늘의 변화]
  바뀌는 건 단 두 가지!
    - 관절:  무릎(엉덩이-무릎-발목)  ->  팔꿈치(어깨-팔꿈치-손목)
    - 푸쉬업 기준:  펴짐 > 160도 / 굽힘 < 90도

  ※ TIP: 푸쉬업은 옆에서(측면) 찍어야 팔이 잘 보입니다!

실행:  python practice1_pushup.py    (종료: q)
필요:  opencv-python==4.10.0.84 / mediapipe==0.10.21 / numpy==1.26.4
========================================================================
"""
import cv2
import numpy as np
import mediapipe as mp

# ----------------------------------------------------------------------
# [재사용 무기 1] 세 점으로 각도를 구하는 함수  (지난 시간에 만든 그대로!)
# ----------------------------------------------------------------------
def calculate_angle(a, b, c):
    """b를 꼭짓점으로 하는 a-b-c 각도(도)를 반환"""
    a = np.array(a)
    b = np.array(b)
    c = np.array(c)
    # Level 1과 같은 벡터 내적 + arccos
    ba = a - b
    bc = c - b
    dot_product = np.dot(ba, bc)
    magnitude_ba = np.linalg.norm(ba)
    magnitude_bc = np.linalg.norm(bc)
    cosine_angle = dot_product / (magnitude_ba * magnitude_bc)
    cosine_angle = np.clip(cosine_angle, -1.0, 1.0)
    return np.degrees(np.arccos(cosine_angle))

# ----------------------------------------------------------------------
# [재사용 무기 2] MediaPipe / 웹캠 준비  (지난 시간 그대로!)
# ----------------------------------------------------------------------
mp_pose = mp.solutions.pose
mp_draw = mp.solutions.drawing_utils
pose = mp_pose.Pose(min_detection_confidence=0.5, min_tracking_confidence=0.5)

cap = cv2.VideoCapture(0)  # 기본 카메라. 안 잡히면 1로 변경

# ----------------------------------------------------------------------
# [상태 변수]  스쿼트 때와 100% 동일한 구조
# ----------------------------------------------------------------------
count = 0
stage = "UP"          # 시작은 팔 편 상태

while True:
    success, frame = cap.read()
    if not success:
        print("❌ 프레임 읽기 실패")
        break

    frame = cv2.flip(frame, 1)
    h, w = frame.shape[:2]

    rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
    results = pose.process(rgb)

    if results.pose_landmarks:
        lm = results.pose_landmarks.landmark

        # --- (1) 관절 고르기: 오른팔 어깨(12) - 팔꿈치(14) - 손목(16) ---
        shoulder = [lm[12].x, lm[12].y]
        elbow    = [lm[14].x, lm[14].y]
        wrist    = [lm[16].x, lm[16].y]

        # --- (2) 각도 재기: 팔꿈치 각도 ---
        angle = calculate_angle(shoulder, elbow, wrist)

        # --- (3)(4) UP/DOWN 판정 + 카운트 (스쿼트의 상태머신 구조 재사용! (각도 기준은 푸쉬업용)) ---
        if angle < 90:                       # 팔 굽힘 = 내려간 상태
            stage = "DOWN"
        if angle > 160 and stage == "DOWN":  # 팔 다시 펴짐 = 올라온 순간!
            stage = "UP"
            count += 1
            print(f"💪 푸쉬업 {count}회!")

        # --- 화면 표시 ---
        mp_draw.draw_landmarks(frame, results.pose_landmarks,
                               mp_pose.POSE_CONNECTIONS)
        ex, ey = int(elbow[0] * w), int(elbow[1] * h)
        cv2.putText(frame, f"{int(angle)}deg", (ex + 10, ey),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.7, (0, 255, 255), 2)

    # 카운트 박스
    cv2.rectangle(frame, (0, 0), (260, 90), (0, 0, 0), -1)
    cv2.putText(frame, "PUSH-UP", (15, 30),
                cv2.FONT_HERSHEY_SIMPLEX, 0.7, (0, 255, 0), 2)
    cv2.putText(frame, f"COUNT: {count}", (15, 70),
                cv2.FONT_HERSHEY_SIMPLEX, 0.9, (255, 255, 255), 2)

    cv2.imshow("AI Push-up Counter", frame)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()

Pose를 준비하고 count = 0, stage = "UP"으로 시작합니다. 팔을 편 자세가 출발점입니다. 반복문은 영상을 RGB로 바꾸어 처리하고, 관절이 잡힌 프레임에서만 좌표를 읽습니다.

팔꿈치가 90도 미만이면 DOWN을 기억하고, 그 뒤 160도를 넘으면 UP으로 바꾸며 한 번만 더합니다. 90~160도에서는 이전 상태를 유지합니다. 스쿼트와 상태머신 구조는 같지만 DOWN 기준은 다릅니다.

화면 표시에서는 비율 좌표에 w, h를 곱해 팔꿈치 옆에 각도 글자를 그립니다. 횟수 상자는 같은 count를 읽어 보여줄 뿐, 별도로 세지 않습니다.

다른 관절의 각도를 활용하는 설계도 가능하지만, 방금의 ‘접혔다 펴지는 관절 하나’ 레시피를 그대로 적용하는 것은 적절하지 않습니다.

스쿼트는 무릎이, 푸쉬업은 팔꿈치가 접혔다 펴집니다. 그래서 그 관절의 각도가 동작을 잘 나타냈습니다. 팔벌려뛰기에서 우리가 확인하려는 것은 팔이 위로 올라갔는지와 다리가 옆으로 벌어졌는지입니다.

관절이 전혀 회전하지 않는다는 뜻이 아닙니다. 팔꿈치의 굽힘보다 손목의 높이와 발 사이 간격이 원하는 자세를 더 직접적으로 알려 준다는 뜻입니다. 같은 함수를 쓸 수 있는지보다 먼저, 무엇을 재야 하는지 물어봐야 합니다.

화면 아래로 갈수록 y가 커지므로 ‘코보다 위에 있다’는 손목.y < 코.y입니다. 예를 들어 코가 0.3, 손목이 0.1이면 손목이 더 위에 있습니다. 두 손목 모두 이 조건을 만족해야 하므로 and로 연결합니다.

화면 안의 좌표는 너비와 높이를 기준으로 한 0~1 비율값입니다. 두 y값의 순서만 비교할 때는 픽셀로 바꿀 필요가 없습니다. Level 1에서 글자를 그릴 위치를 구할 때는 화면 크기를 곱했지만, 여기서는 위치 관계만 판단하므로 그대로 비교합니다.

abs는 좌우 좌표의 차이를 양수인 간격으로 바꿉니다. 발 간격을 고정된 픽셀 수로 정하면 체격이나 카메라와의 거리에 따라 조건이 달라집니다. 대신 같은 화면 속 자기 어깨너비와 비교하면 사람마다 크기가 다른 영향을 줄일 수 있습니다.

x축 간격끼리 비교하므로 둘 다 화면 너비를 곱해도 비율은 같습니다. 화면 해상도를 바꾸어도 같은 방식으로 비교할 수 있지만, 촬영 방향이나 관절 인식 오차까지 없어지는 것은 아닙니다.

1.3은 수학적으로 정해진 상수가 아니라 실습에서 시험해 정한 조정값입니다. 어깨너비보다 조금 더 벌려야 인정하도록 여유를 둔 것입니다. 값을 높이면 더 넓게 벌려야 참이 되고, 낮추면 더 쉽게 참이 됩니다.

"""
========================================================================
practice2_jumpingjack.py  -  팔벌려뛰기 카운터 (★위치 기반★)
========================================================================
[오늘의 핵심 "아하!" 포인트]
  팔벌려뛰기는 '각도'로 잡기 어렵다!
    - 스쿼트/푸쉬업 = 관절이 "접혔다 펴졌다" → 각도가 딱 맞음
    - 팔벌려뛰기   = 팔이 "위로", 다리가 "옆으로" → 각도보다 '위치/거리'!

  그래서 측정 방법을 바꾼다:
    - 팔 올림 판정 :  손목 y < 코 y      (y는 작을수록 화면 위쪽!)
    - 다리 벌림 판정:  두 발목 사이 x거리 > 어깨너비       (벌어졌나?)

  ※ MediaPipe 좌표는 0~1 비율값이라 화면 크기와 무관하게 비교 가능!

실행:  python practice2_jumpingjack.py    (종료: q)
========================================================================
"""
import cv2
import mediapipe as mp

mp_pose = mp.solutions.pose
mp_draw = mp.solutions.drawing_utils
pose = mp_pose.Pose(min_detection_confidence=0.5, min_tracking_confidence=0.5)

cap = cv2.VideoCapture(0)  # 기본 카메라. 안 잡히면 1로 변경

count = 0
stage = "DOWN"        # 시작은 팔 내린 상태(차렷)

while True:
    success, frame = cap.read()
    if not success:
        print("❌ 프레임 읽기 실패")
        break

    frame = cv2.flip(frame, 1)
    rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
    results = pose.process(rgb)

    if results.pose_landmarks:
        lm = results.pose_landmarks.landmark

        # --- 필요한 위치 가져오기 ---
        nose       = lm[0]
        l_wrist    = lm[15]
        r_wrist    = lm[16]
        l_shoulder = lm[11]
        r_shoulder = lm[12]
        l_ankle    = lm[27]
        r_ankle    = lm[28]

        # --- (측정 1) 두 손목이 모두 코보다 위에 있나? (팔 올림) ---
        arms_up = (l_wrist.y < nose.y) and (r_wrist.y < nose.y)

        # --- (측정 2) 발 사이 거리가 어깨너비보다 넓나? (다리 벌림) ---
        shoulder_width = abs(l_shoulder.x - r_shoulder.x)
        ankle_gap      = abs(l_ankle.x - r_ankle.x)
        legs_open      = ankle_gap > shoulder_width * 1.3

        # --- 동작 판정: 팔도 올리고 다리도 벌리면 "벌린 자세(UP)" ---
        is_open = arms_up and legs_open

        # --- 카운트 (스쿼트와 똑같은 상태머신!) ---
        if not is_open:                       # 모은 자세
            stage = "DOWN"
        if is_open and stage == "DOWN":       # 모았다가 벌린 순간!
            stage = "UP"
            count += 1
            print(f"🤸 팔벌려뛰기 {count}회!")

        mp_draw.draw_landmarks(frame, results.pose_landmarks,
                               mp_pose.POSE_CONNECTIONS)

        # 현재 판정 상태 표시 (디버깅용 - 학생들이 원리를 보게)
        cv2.putText(frame, f"arms_up: {arms_up}", (15, 130),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.6, (0, 255, 255), 2)
        cv2.putText(frame, f"legs_open: {legs_open}", (15, 160),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.6, (0, 255, 255), 2)

    cv2.rectangle(frame, (0, 0), (300, 90), (0, 0, 0), -1)
    cv2.putText(frame, "JUMPING JACK", (15, 30),
                cv2.FONT_HERSHEY_SIMPLEX, 0.7, (255, 0, 255), 2)
    cv2.putText(frame, f"COUNT: {count}", (15, 70),
                cv2.FONT_HERSHEY_SIMPLEX, 0.9, (255, 255, 255), 2)

    cv2.imshow("AI Jumping Jack Counter", frame)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()

스쿼트와 푸쉬업은 몸이나 팔을 편 상태인 "UP"에서 시작했습니다. 팔벌려뛰기는 팔을 내리고 발을 모은 차렷 자세가 출발점이므로 stage = "DOWN"으로 시작합니다. UP과 DOWN은 모든 운동에서 같은 신체 자세를 뜻하는 이름이 아니라, 각 운동에서 정한 두 상태의 이름입니다.

카운트의 핵심 구조는 동일합니다. DOWN을 기억하고 있다가 UP 조건이 관측되는 순간에만 1을 더합니다. 그래서 이 파일은 모았다가 벌리는 순간을 셉니다. 다만 구현상 not is_open이면 DOWN이므로 손이나 발 중 하나만 조건을 벗어나도 다시 DOWN이 됩니다. 완전히 차렷 자세인지까지 검사하는 코드는 아닙니다.

화면에 arms_up과 legs_open을 그대로 표시하는 것은 장식이 아닙니다. 횟수가 안 오를 때 어느 조건이 False인지 확인하면, 손을 더 올려야 하는지 발 간격을 점검해야 하는지 찾을 수 있습니다. 결과뿐 아니라 중간 판단을 보여 주는 것이 디버깅에 도움이 됩니다.

if / elif 자체가 나쁜 문법은 아닙니다. 여기서 피하려는 것은 동일한 동작을 여러 곳에서 따로 관리하는 중복입니다.

앞의 ‘큰 그림’을 다시 떠올려 보세요

달라지는 것은 지금 자세가 UP인지 DOWN인지 판단하는 방법입니다. 그대로인 것은 DOWN을 기억했다가 UP으로 바뀔 때 1을 더하는 로직입니다. 다른 부분만 함수로 빼고, 같은 부분은 하나만 두면 됩니다.

입력과 출력 모양을 맞추면 바꿔 끼울 수 있습니다

세 함수는 모두 랜드마크 목록 lm 하나를 받습니다. 반환값은 공통 약속인 "UP", "DOWN", None 중 하나입니다. 관절이나 계산법이 달라도 호출하는 쪽은 이 약속만 알면 됩니다.

함수 안에서는 운동에 맞게 측정하고, 함수 밖에서는 반환된 상태만 읽겠습니다. 아래에서 같은 함수 모양 속에 서로 다른 판단이 들어가는지 확인하세요.

def jack_state(lm):

    shoulder_width = abs(lm[11].x - lm[12].x)

"state": squat_state는 함수를 지금 실행하는 것이 아니라, 나중에 호출할 함수를 저장하는 표현입니다. 반면 squat_state(...)처럼 괄호를 붙이면 그 자리에서 호출해 반환값을 얻게 됩니다. squat_state()만 쓰면 필요한 lm 인자가 없어 오류도 납니다.

ord('1')은 문자 ‘1’의 코드값인 49입니다. 영상 창에서 1번 키를 눌러 받은 값과 이 키를 연결합니다. "name"은 화면 이름, "state"는 판단 방법, "color"는 OpenCV의 BGR 색입니다.

판단 알고리즘 자체는 함수 안의 코드로 남습니다. 대신 어떤 운동에 어떤 함수와 표시 정보를 연결할지를 데이터로 정의했습니다. 선택 부분이 운동별 알고리즘을 알 필요가 없어진 것입니다.

        # ★ 운동마다 다른 부분: 자세 판정 (함수만 갈아끼움) ★
        state = current["state"](lm)

        # ★ 모든 운동이 공유하는 부분: 카운트 로직 ★
        if state == "DOWN":
            stage = "DOWN"
        elif state == "UP" and stage == "DOWN":
            stage = "UP"
            count += 1
  1. current는 현재 선택한 운동의 정보 묶음입니다.
  2. current["state"]로 그 운동의 판정 함수를 꺼냅니다.
  3. 바로 뒤의 (lm)으로 현재 랜드마크를 전달하며 호출합니다.

"""
========================================================================
practice3_multi_coach.py  -  만능 운동 코치 (종목 전환)
========================================================================
[오늘의 핵심: 추상화 / 데이터로 설계하기]
  스쿼트 / 푸쉬업 / 팔벌려뛰기 ... 운동이 달라도
  "카운트 로직"은 완전히 똑같다!  (UP <-> DOWN 상태머신)

  달라지는 건 "지금 자세가 UP이냐 DOWN이냐"를 판단하는 부분 뿐.
  -> 그 판단 부분만 함수로 따로 빼고,
     카운트 로직은 하나로 공유하자!

  조작:  [1] 스쿼트   [2] 푸쉬업   [3] 팔벌려뛰기   [q] 종료
========================================================================
"""
import cv2
import numpy as np
import mediapipe as mp

def calculate_angle(a, b, c):
    """b를 꼭짓점으로 하는 a-b-c 각도(도)를 반환"""
    a = np.array(a)
    b = np.array(b)
    c = np.array(c)
    # Level 1과 같은 벡터 내적 + arccos
    ba = a - b
    bc = c - b
    dot_product = np.dot(ba, bc)
    magnitude_ba = np.linalg.norm(ba)
    magnitude_bc = np.linalg.norm(bc)
    cosine_angle = dot_product / (magnitude_ba * magnitude_bc)
    cosine_angle = np.clip(cosine_angle, -1.0, 1.0)
    return np.degrees(np.arccos(cosine_angle))

# ----------------------------------------------------------------------
# [운동별 "자세 판정" 함수]  각 함수는 "UP" / "DOWN" / None 을 반환
#   None = 애매한 중간 자세 (상태를 바꾸지 않음)
# ----------------------------------------------------------------------
def squat_state(lm):
    hip   = [lm[24].x, lm[24].y]
    knee  = [lm[26].x, lm[26].y]
    ankle = [lm[28].x, lm[28].y]
    angle = calculate_angle(hip, knee, ankle)
    if 70 < angle <= 100: return "DOWN"  # 정자세 구간
    if angle > 160:  return "UP"
    return None

def pushup_state(lm):
    shoulder = [lm[12].x, lm[12].y]
    elbow    = [lm[14].x, lm[14].y]
    wrist    = [lm[16].x, lm[16].y]
    angle = calculate_angle(shoulder, elbow, wrist)
    if angle < 90:   return "DOWN"
    if angle > 160:  return "UP"
    return None

def jack_state(lm):
    arms_up = (lm[15].y < lm[0].y) and (lm[16].y < lm[0].y)
    shoulder_width = abs(lm[11].x - lm[12].x)
    legs_open = abs(lm[27].x - lm[28].x) > shoulder_width * 1.3
    return "UP" if (arms_up and legs_open) else "DOWN"

# ----------------------------------------------------------------------
# [운동을 "데이터"로 정의]  이름 + 판정함수 + 색깔
#   새 운동을 추가하고 싶으면? 여기에 한 줄만 추가하면 끝!
# ----------------------------------------------------------------------
EXERCISES = {
    ord('1'): {"name": "SQUAT",        "state": squat_state,  "color": (0, 255, 0)},
    ord('2'): {"name": "PUSH-UP",      "state": pushup_state, "color": (0, 200, 255)},
    ord('3'): {"name": "JUMPING JACK", "state": jack_state,   "color": (255, 0, 255)},
}

mp_pose = mp.solutions.pose
mp_draw = mp.solutions.drawing_utils
pose = mp_pose.Pose(min_detection_confidence=0.5, min_tracking_confidence=0.5)
cap = cv2.VideoCapture(0)  # 기본 카메라. 안 잡히면 1로 변경

current = EXERCISES[ord('1')]   # 시작 운동 = 스쿼트
count = 0
stage = "UP"

while True:
    success, frame = cap.read()
    if not success:
        break
    frame = cv2.flip(frame, 1)
    rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
    results = pose.process(rgb)

    if results.pose_landmarks:
        lm = results.pose_landmarks.landmark

        # ★ 운동마다 다른 부분: 자세 판정 (함수만 갈아끼움) ★
        state = current["state"](lm)

        # ★ 모든 운동이 공유하는 부분: 카운트 로직 ★
        if state == "DOWN":
            stage = "DOWN"
        elif state == "UP" and stage == "DOWN":
            stage = "UP"
            count += 1

        mp_draw.draw_landmarks(frame, results.pose_landmarks,
                               mp_pose.POSE_CONNECTIONS)

    cv2.rectangle(frame, (0, 0), (340, 95), (0, 0, 0), -1)
    cv2.putText(frame, current["name"], (15, 32),
                cv2.FONT_HERSHEY_SIMPLEX, 0.8, current["color"], 2)
    cv2.putText(frame, f"COUNT: {count}", (15, 75),
                cv2.FONT_HERSHEY_SIMPLEX, 1.0, (255, 255, 255), 2)
    cv2.putText(frame, "[1]Squat [2]Push-up [3]Jack [q]Quit",
                (15, frame.shape[0] - 20),
                cv2.FONT_HERSHEY_SIMPLEX, 0.55, (200, 200, 200), 1)

    cv2.imshow("AI Multi Coach", frame)

    key = cv2.waitKey(1) & 0xFF
    if key == ord('q'):
        break
    if key in EXERCISES:                 # 종목 전환!
        current = EXERCISES[key]
        count = 0                        # 새 운동 시작 -> 0부터
        stage = "UP"
        print(f"➡️  {current['name']} 모드로 전환!")

cap.release()
cv2.destroyAllWindows()

종목 전환에서는 current = EXERCISES[key]로 정보 묶음을 바꾸고 횟수와 상태를 초기화합니다. 판정 함수, 이름, 색이 함께 바뀌므로 선택 코드에 운동별 세부 동작을 넣을 필요가 없습니다.

각도가 160도 이하가 되거나 관절이 인식되지 않으면 시간이 늘지 않습니다. 자세를 다시 맞추면 이전 기록에 이어 누적합니다. 따라서 화면의 값은 중단 없이 버틴 최장 시간이 아니라 조건을 만족한 시간의 합입니다.

"""
========================================================================
practice5_plank.py  -  (보너스) 플랭크 버티기 타이머
========================================================================
[새로운 개념: 횟수가 아니라 "시간"을 재는 상태머신]
  스쿼트/푸쉬업/팔벌려뛰기 = 동작을 "셈" (반복 횟수)
  플랭크                  = 자세를 "버팀" (지속 시간!)

  -> 같은 상태머신이지만, UP일 때 +1 하는 대신 '시간을 누적'한다.

[플랭크 자세 판정]
  몸이 일직선인가?  어깨(12)-엉덩이(24)-발목(28) 각도가 약 160~180도
  (구부정하면 각도가 작아짐 -> 타이머 일시정지!)

실행:  python practice5_plank.py    (종료: q / 리셋: r)
========================================================================
"""
import cv2
import time
import numpy as np
import mediapipe as mp

def calculate_angle(a, b, c):
    """b를 꼭짓점으로 하는 a-b-c 각도(도)를 반환"""
    a = np.array(a)
    b = np.array(b)
    c = np.array(c)
    # Level 1과 같은 벡터 내적 + arccos
    ba = a - b
    bc = c - b
    dot_product = np.dot(ba, bc)
    magnitude_ba = np.linalg.norm(ba)
    magnitude_bc = np.linalg.norm(bc)
    cosine_angle = dot_product / (magnitude_ba * magnitude_bc)
    cosine_angle = np.clip(cosine_angle, -1.0, 1.0)
    return np.degrees(np.arccos(cosine_angle))

mp_pose = mp.solutions.pose
mp_draw = mp.solutions.drawing_utils
pose = mp_pose.Pose(min_detection_confidence=0.5, min_tracking_confidence=0.5)
cap = cv2.VideoCapture(0)  # 기본 카메라. 안 잡히면 1로 변경

held_time = 0.0          # 누적 버틴 시간(초)
last_t = time.time()     # 직전 프레임 시각

while True:
    success, frame = cap.read()
    if not success:
        break
    frame = cv2.flip(frame, 1)
    rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
    results = pose.process(rgb)

    now = time.time()
    dt = now - last_t        # 이번 프레임이 걸린 시간
    last_t = now

    is_plank = False
    if results.pose_landmarks:
        lm = results.pose_landmarks.landmark
        body_angle = calculate_angle([lm[12].x, lm[12].y],
                                     [lm[24].x, lm[24].y],
                                     [lm[28].x, lm[28].y])
        is_plank = body_angle > 160      # 몸이 충분히 일직선인가?

        # ★ 카운트 대신 '시간 누적' ★
        if is_plank:
            held_time += dt

        mp_draw.draw_landmarks(frame, results.pose_landmarks, mp_pose.POSE_CONNECTIONS)
        cv2.putText(frame, f"body: {int(body_angle)}deg", (15, 150),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.6, (0, 255, 255), 2)

    color = (0, 255, 0) if is_plank else (0, 0, 255)
    status = "HOLDING!" if is_plank else "FIX POSTURE"

    cv2.rectangle(frame, (0, 0), (360, 110), (0, 0, 0), -1)
    cv2.putText(frame, "PLANK", (15, 35),
                cv2.FONT_HERSHEY_SIMPLEX, 0.8, (255, 255, 0), 2)
    cv2.putText(frame, f"{held_time:5.1f} s", (15, 95),
                cv2.FONT_HERSHEY_SIMPLEX, 1.6, (255, 255, 255), 3)
    cv2.putText(frame, status, (190, 60),
                cv2.FONT_HERSHEY_SIMPLEX, 0.8, color, 2)

    cv2.imshow("AI Plank Timer", frame)
    key = cv2.waitKey(1) & 0xFF
    if key == ord('q'):
        break
    if key == ord('r'):
        held_time = 0.0

cap.release()
cv2.destroyAllWindows()

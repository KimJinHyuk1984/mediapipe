# Phase 3-D 검증

검증 환경: Windows Chrome, CSS viewport 1920×950, 로컬 HTTP `/mediapipe/level1/`.

## 판정과 결과

- 변경 전에도 이 환경에서는 기본 76개를 실제 컨테이너 기준으로 검사했을 때 넘침이 재현되지 않았다. 사용자 환경의 원인을 특정했다고 주장하지 않는다.
- 기존 코드는 문서 높이가 아니라 자식 `.presentation-content.scrollHeight`를 비교했다. 이제 `.presentation-viewport.scrollHeight > clientHeight`를 직접 판정하며 `reportPresentationOverflow()`도 동일한 함수를 사용한다.
- 수정 후 기본 76개 및 S 포함 90개를 방향키로 전부 순회했다. 모든 조각의 컨테이너는 **775 / 775px**, 배너 0개, 이미지·위젯·슬라이더의 상하 잘림 0개, 코드 내부 세로 넘침 0개였다.
- 개별 측정값은 `PHASE-3D-MEASUREMENTS.csv`, 재실행 검증은 `verify-phase3d.cjs`에 있다. 저장소 루트에서 실행하며 Playwright와 부모 디렉터리의 포트 8000 HTTP 서버가 필요하다.
- 텍스트는 본문 24px / 코드 20px 이하로 축소하지 않는다. 하한에서 남는 넘침 목록: 없음.
- 이미지·위젯을 자동 판별한다. 조각 마커의 `data-slide-fit="contain"`으로 전체 맞춤을 명시할 수도 있다.

## 화면 맞춤 수치

이미지는 원본 픽셀 대비 표시 비율이며 CSS transform을 사용하지 않는다. 캡션은 본문 28px을 유지한다.

| 기본 번호 | S 포함 번호 | 대상 | 표시 크기 또는 배율 |
|---|---|---|---|
| 2 | 2 | 완성 화면 이미지 | 약 1301×709px · 0.9292배 |
| 25 | 25 | OpenCV 이미지 | 약 1270×709px · 0.9232배 |
| 27 | 27 | MediaPipe 인포그래픽 | 약 1159×647px · 0.8424배 |
| 39 | 39 | 랜드마크 이미지 | 약 530×709px · 0.5912배 |
| 45·46·58 | 46·47·59 | 수학·상태머신 이미지 | 약 1270×709px · 0.9232배 |
| 43 | 44 | landmark-map | 전체 transform 없음 · 1배 |
| 53 | 54 | angle-slider | transform 0.9404배 |

- angle-slider의 실제 본문 약 26.33px, 계산식 약 22.57px, SVG A/B/C 표기 약 22.4px. 슬라이더 상단과 위젯 하단이 모두 가용 영역 안에 있다.
- landmark-map은 `lecture.css`의 발표 전용 좌우 배치와 행 간격을 조정했다. 본문 28px, 코드 24px, 관절 번호 18px이다. 작은 관절 번호는 선택 시 오른쪽의 큰 이름·번호로도 확인할 수 있다.
- WebP 인포그래픽 내부 글자는 래스터 픽셀이므로 CSS 폰트 크기로 측정할 수 없다. 실제 렌더에서 전체 이미지와 캡션을 확인했다.
- 1920×950에서는 추가 분할이 필요한 조각이 없었다. 더 작은 표시 영역은 별도로 판단해야 하며, 위젯 축소 하한은 0.6이다.

## 조작 및 회귀 검증

- 43번: 마우스로 왼쪽 무릎 선택, 터치로 오른쪽 무릎 선택, 키보드 방향키 이동. 발표 조각은 이동하지 않음.
- 53번: 실제 화면 좌표에서 마우스 드래그(138도), 터치 드래그(82도), 방향키로 1도 변경. 조각 이동과 충돌하지 않음.
- 1920×800 추가 검사: angle-slider 0.7579배, landmark-map 0.9873배에서도 마우스/터치 좌표가 맞으며 잘림 없음. 이때 angle-slider 본문은 약 21.2px이므로 950px 높이보다 가독성이 낮다.
- 라이트/다크와 일반 전환 애니메이션에서도 검사했다. 40~180도 전체 슬라이더 값에서 추가 넘침 없음.
- 발표 종료 후 375px / 1920px 읽기 화면의 섹션·이미지·코드 위치와 크기는 진입 전과 정확히 일치했다. 이미지에 적용한 임시 스타일도 복원된다.
- 페이지 오류 0건. 본문·코드 원본 및 이전 검증 보고서는 수정하지 않았다.

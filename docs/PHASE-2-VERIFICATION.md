# Phase 2 위젯 검증 보고

검증일: 2026-09-07. Chrome + Playwright, Python HTTP 서버의
`/mediapipe/level1/`에서 확인했습니다.

이번 단계에서 수정한 파일은 `assets/js/widgets.js`, `assets/css/lecture.css`,
`level1/index.html`뿐입니다. `base.css`, `tokens.css`, `shared.js`에는 변경이 없습니다.

세 위젯은 모두 기존 `window.WIDGETS` 등록과 자동 마운트 구조를 사용합니다.
위젯 생성 중 오류가 나거나 `widgets.js` 요청이 실패하면 호스트 내부의 정적 설명이
그대로 남도록 했습니다. 실제로 스크립트 요청을 차단한 브라우저에서 위젯 0개와
정적 대체 설명 3개가 표시되고 페이지가 렌더링되는 것을 확인했습니다.

| 검증 | 결과 |
|---|---|
| landmark-map 마운트·33점·선택·토글 | 통과, 33개 점과 6개 기본 강조, 25번 선택 시 이름·코드 갱신 |
| angle-slider 40~180도 계산 | 통과, 141개 각도 모두 내적/arctan2 차이 ≤ 0.0001도 |
| 판정 연동·프리셋 | 통과, 네 판정 구간과 색상 상태가 각도에 따라 갱신 |
| state-machine 정상 재생 | 통과, 단순 비교 22회 / 상태머신 1회 |
| 너무 깊게 앉기 | 통과, 170→95→60→95→170에서 상태머신 1회 |
| 정자세 없이 주저앉기 | 통과, 170→65→170에서 상태머신 0회 |
| 초기화·수동 슬라이더 | 통과, 상태·카운터·전이 메시지 초기화 및 각도 키보드 조작 |
| 키보드 조작 | 통과, 랜드마크 Enter·방향키, range 방향키, 버튼 Tab/Enter 경로 확인 |
| 발표 모드 | 통과, 위젯 range에 포커스한 상태에서 방향키가 섹션 이동을 일으키지 않음 |
| reduced motion | 통과, 자동 재생이 즉시 최종 결과로 이동하고 상태머신 1회 기록 |
| 375px | 통과, 문서 폭 증가 없음, range·버튼 조작 가능 |
| 로드 실패 대체 | 통과, widgets.js 차단 시 정적 설명 3개·페이지 정상 |
| 색상 정책 | 통과, widgets.js·추가 lecture.css에서 색상 리터럴 없음. 테마 변수만 사용 |
| 기존 공통 파일 | 통과, phase 2 변경분에서 base.css·tokens.css·shared.js 제외 |

각도 위젯은 화면에서 비교를 위해 arctan2를 함께 계산하지만, Level 1 실습 파일의
정본과 본문 계산 방식인 벡터 내적 + arccos는 변경하지 않았습니다.
상태머신의 ‘정자세 없이’ 시나리오는 중간 각도를 보간하지 않고 170→65→170의
관측값을 즉시 전환하여, GOOD SQUAT 구간을 관측하지 않으면 세지 않는 규칙을 보여 줍니다.

색상은 `--accent`, `--accent-text`, `--accent-soft`, `--text`, `--surface`,
`--surface-2`, `--bg`, `--border`, `--control-border`, `--warn` 등 기존 토큰만
참조합니다. 외부 라이브러리·네트워크 데이터·위젯용 fetch는 사용하지 않았습니다.

검증 스크립트: [verify-phase2.cjs](verify-phase2.cjs).
커밋·푸시·배포는 수행하지 않았습니다.

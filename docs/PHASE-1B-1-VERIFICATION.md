# Phase 1-B-1 검증 결과

검증일: 2026-09-07. 설치된 Chrome과 Playwright로 Python HTTP 서버의
/mediapipe/level1/을 열어 검사했습니다.

## 작성 범위

mission, demo, how, learn, setup의 실제 콘텐츠를 작성했습니다.
나머지 7개 섹션은 기존 TODO 주석과 제목만 유지합니다.
스타일은 lecture.css에만 추가했으며, 이번 작업에서 base.css와 tokens.css는 수정하지 않았습니다.

## 콘텐츠 보충 사항

- 90도 이하 기준은 개요로 유지하면서, 다시 일어났을 때 한 번만 센다고 설명했습니다.
  복원 문서의 상세 구현은 별도 각도 기준을 사용하므로 후속 섹션에서 구체화하도록 안내했습니다.
- 요청된 실행 결과의 OpenCV 4.11.0을 그대로 싣고, 권장 4.10.0.84와 다른 예시임을 명시했습니다.
- NumPy 호환성 설명은 이 수업의 MediaPipe 0.10.21로 범위를 한정했습니다.
  참고: [MediaPipe 배포 정보](https://pypi.org/project/mediapipe/0.10.21/).
- requirements.txt와 test_install.py는 현재 저장소에 없어 강사 제공 실습 폴더를 먼저 준비하도록 안내했습니다.
  이번 범위에서 해당 파일을 새로 만들거나 Python 패키지 설치·실제 웹캠 테스트를 수행하지 않았습니다.
  페이지의 터미널 출력은 요청받은 예시이며 이 환경의 실행 결과가 아닙니다.

나머지 섹션 작성, 커밋, 푸시, 배포는 수행하지 않았습니다.

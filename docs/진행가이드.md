## 단계별 학습 포인트 (왜 이 순서인가)
1. **푸쉬업** — *자신감 단계.* "관절 3개와 기준 숫자만 바꾸면 된다"를 몸으로 확인. 스쿼트 코드와 거의 동일.
2. **팔벌려뛰기** — *오늘의 반전.* 각도로는 안 잡힘 → 좌표(y 비교)·거리(x 차이)로 측정. "도구는 동작에 맞춘다"를 가르침.
3. **만능 코치** — *추상화.* 운동을 `dict` 데이터로 정의, 판정 함수만 갈아끼우고 카운트 로직은 공유. 하드코딩 → 데이터 기반 설계.
4. **완성판/경기** — `mode` 변수로 연습/도전/결과를 오가는 또 하나의 상태머신.
5. **플랭크(보너스)** — 횟수 대신 *시간 누적*. 같은 상태머신의 변형.

## 자주 나오는 질문/트러블슈팅
- **카메라가 안 켜져요** → `cv2.VideoCapture(0)`의 0을 1로 변경 (외장캠/노트북캠 번호 차이).
- **카운트가 안 올라가요** → 동작 끝까지(굽힘/펼침) 해야 기준 통과. 화면의 각도 값 확인.
- **팔벌려뛰기가 한 번에 여러 번 세요** → `* 1.3` 배수를 키우거나, 손목 기준을 코→어깨로 조정.
- **푸쉬업이 정면에서 안 잡혀요** → 측면으로 촬영.
